# 量潮众包管理档案

## 目录约定

本仓库一级文件夹**按业务划分**，以方便独立核算。各业务内容各自维护、互不混淆。

```
data/profile/
├── README.md              # 仓库说明
├── AGENTS.md              # AI 维护规则
├── quanttide-github/      # 量潮云 / GitHub 相关任务
├── quanttide-legal/       # 法务相关任务
├── quanttide-org/         # 组织管理相关任务
├── quanttide-project/     # 项目管理相关任务
├── quanttide-relation/    # 公关相关任务
├── quanttide-strategy/    # 战略管理相关任务
└── <业务>/
    └── ...
```
