# 量潮众包管理档案

## 目录约定

本仓库一级文件夹**按来源划分**：需求来自哪个来源，就入哪个目录；各目录内容独立维护、互不混淆。业务显示名以档案元数据「业务」为准。

```
data/profile/
├── README.md              # 仓库说明
├── AGENTS.md              # AI 维护规则
├── quanttide-github/      # 量潮云 / GitHub 相关任务
├── quanttide-legal/       # 法务相关任务
├── quanttide-org/         # 组织管理相关任务
├── quanttide-project/     # 项目管理相关任务
├── quanttide-relation/    # 公关相关任务
├── quanttide-strategy/    # 战略管理相关任务
├── quanttide-learn/       # 学习任务书（集中自 quanttide-learn 学习档案）
├── quanttide-academy/     # 实训任务书（集中自 quanttide-academy 实训基地意图）
└── <来源>/
    └── ...
```

档案是任务书的事实源，统一上线 qtclass lite；qtcrowd 站点任务清单与本仓解耦（已下线）。
